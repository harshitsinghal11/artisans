# Design System: Colors

This document defines the complete color system for the AI-Driven Market Linkage App based on the original palette. It is built to support both Light and Dark modes while maintaining a warm, earthy, and organic aesthetic suitable for Indian handicrafts.

## Original Base Hex Codes
- `#F5FAE1` (Very pale yellow-green)
- `#EEE6CA` (Pale warm beige)
- `#E5BEB5` (Pale dusty rose)
- `#896C6C` (Muted rose-brown)
- `#BB6653` (Terracotta)

---

## Theme Mapping

### Light Mode
| Token | Hex | Usage |
| :--- | :--- | :--- |
| **Background** | `#F5FAE1` | Main app background |
| **Foreground** | `#2D2424` | Primary text (Deep warm dark brown for contrast) |
| **Card / Surface** | `#FFFFFF` | Component backgrounds (cards, dialogs) |
| **Card Foreground** | `#2D2424` | Text on cards |
| **Primary** | `#BB6653` | Primary buttons, active states, key accents (Terracotta) |
| **Primary Foreground** | `#F5FAE1` | Text on primary buttons |
| **Secondary** | `#E5BEB5` | Secondary buttons, subtle accents (Pale dusty rose) |
| **Secondary Foreground**| `#896C6C` | Text on secondary elements |
| **Muted** | `#EEE6CA` | Disabled states, secondary backgrounds (Pale warm beige) |
| **Muted Foreground** | `#896C6C` | Secondary text, placeholders |
| **Border / Input** | `#E5BEB5` | Dividers, input borders |
| **Ring** | `#BB6653` | Focus rings for accessibility |

| Token | Hex | Usage |
